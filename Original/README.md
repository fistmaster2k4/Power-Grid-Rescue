# Original ROCCAT Power-Grid materials

This folder preserves unmodified historical ROCCAT Power-Grid distributions and development resources, separate from restoration patches and newly written tooling.

- [Android](Android/) — original Android materials.
- [Installer](Installer/) — original installation materials.
- [SDK v1.1](SDK-v1.1/) — official SDK ZIP, original PDF guides, bundled C++ and JavaScript Doxygen documentation, and a technical reference index.
