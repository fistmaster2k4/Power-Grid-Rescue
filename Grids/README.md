# Power-Grid Grids

This folder contains grids for **ROCCAT Power-Grid**, including examples rescued from the original Power-Grid ecosystem and new grids created for the restored application.

## Browse the grids

- **[Rescued](Rescued/)** — recovered grids preserved for use with Power-Grid Rescue.
- **[New](New/)** — newly created grids for the restored Power-Grid application.

## New to Power-Grid? Start here

Before you dive into the files, have a look at **[ROCCAT Power-Grid: Smart Grid Gaming Software — Tom's Hardware (2013)](https://www.tomshardware.com/reviews/smart-grid-gaming-software,3622.html)**.

This original review does an excellent job of showing **what Power-Grid was designed to do**: turning a phone or tablet into a customisable PC control surface, not just a collection of macro buttons. It also walks through creating and configuring your own grids, with screenshots of the original editor.

For the hands-on grid-building section, see **[How to Create a Custom Grid](https://www.tomshardware.com/reviews/smart-grid-gaming-software,3622-4.html)**.

It's a useful introduction for first-time users, and an excellent snapshot of the software in its original form. The screenshots are from the 2013 release; the Power-Grid Rescue project restores the original workflow for offline use.

## Using these grids

Install and launch the restored Power-Grid Windows application, then import the grid package through Power-Grid. Connect your Android Power-Grid controller to the Windows host to use the grid on your device.

Some historical grids rely on other applications, plugins or resources. Those dependencies may still be needed, even with the restored Power-Grid client.

For the patched Windows and Android clients, see **[Power-Grid Rescue](../README.md)** and the repository's [Releases](https://github.com/fistmaster2k4/Power-Grid-Rescue/releases).
