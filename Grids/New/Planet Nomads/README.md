# Planet Nomads

**Author:** Fistmaster2k4  
**Website:** [Planet Nomads Multiplayer](https://github.com/fistmaster2k4/Planet-Nomads-Multiplayer)

This Grid is a starter for Planet Nomads now that the Multiplayer mod is live. This gives 5 basic buttons all based on the master custom button style to allow for easy building and assigning of controls for switching of electronics, lights, printers and vehicle drivetrain.

## Installation and use

1. Install the restored Power-Grid Windows host and patched Android client from [Power-Grid Rescue releases](https://github.com/fistmaster2k4/Power-Grid-Rescue/releases).
2. Import `PlanetNomads.rpgp` into the Windows Power-Grid application and add the grid to the active bar.
3. Connect your Android device and synchronise the grid.
4. In Planet Nomads, assign the corresponding keyboard shortcut to the equipment or electrical switch you wish to control. A single switch can feed several devices, such as a pair of headlights.
5. With the game active, tap a grid button to send its assigned shortcut.

No additional game plugin is required. The grid uses Planet Nomads' existing shortcut system and can be used in single-player or with the multiplayer mod. The green ON graphic appears while a button is pressed; it does not report the actual device state. Equipment switching and electrical grouping are handled by the game.

The grid uses Power-Grid's Master custom buttons, with interchangeable device artwork, a common frame, gloss and active overlay, and editable labels. You can customise the controls and their shortcuts in the editor.

The grid has been displayed successfully on a Samsung Galaxy Note 10.1 (GT-N8010) using the patched Android client. If the original ROCCAT Android application is still installed, uninstall it before installing the patched APK because the signing certificates differ.
