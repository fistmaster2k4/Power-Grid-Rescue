VRE Server Monitor - Power-Grid 0.461

1. Import VREServer_Plugin_v0.1.6.rpgp and approve native plugin installation.
2. Import VRE_Server_0.1.3.rpgp to add the Vulkan Server grid.
3. If Power-Grid requests permission to load vreserver.dll, approve it.
4. The grid uses vulkangame.online:5128. Host and port are editable per control.

# Plugin Details
This plugin was created to investigate the possibility of building custom plugins for Power-Grid without the missing Power-Grid SDK
