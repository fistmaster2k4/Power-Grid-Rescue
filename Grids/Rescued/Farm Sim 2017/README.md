# Farming Simulator 2017 — Rescued Power-Grid Grids

This folder contains recovered ROCCAT Power-Grid `.rpgp` files created for **Farming Simulator 2017**.

These files are preserved as community-created material from the original Power-Grid ecosystem. They are included so they remain usable with Power-Grid Rescue and so the original grid library does not disappear completely.

## Original compatibility note

The recovered EndlessDark grids include a note regarding the hazard/beacon control. Power-Grid did not correctly recognise the `Pos1` / Home key in that configuration, so the grid expected a secondary in-game binding of:

`Ctrl+R`

If that control does not work with a current Farming Simulator 2017 configuration, check the game's key bindings and restore or replace the expected secondary binding.

## Using these grids

Import the `.rpgp` file into the restored Windows Power-Grid application using the normal Power-Grid grid import workflow.

Because these grids were authored for a specific game version and control setup, some commands may depend on the original creator's key bindings or installed mods. If a control behaves differently, compare the game's current bindings with the actions configured in the grid.
