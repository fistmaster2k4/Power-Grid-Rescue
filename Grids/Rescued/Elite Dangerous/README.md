# Elite Dangerous — Rescued Power-Grid Grids

This folder contains recovered ROCCAT Power-Grid `.rpgp` files created for **Elite Dangerous**.

These files are preserved as community-created material from the original Power-Grid ecosystem. They are included so they remain available for users of Power-Grid Rescue and for historical reference.

## Included grids

### BloodSteyn Grids

File:

`BloodSteyn Grids.rpgp`

Creator: **BloodSteyn**

This is a multi-grid Elite Dangerous control set. The recovered package includes functions and shortcuts for common ship operations such as docking, high wake, pit-stop style functions, Galaxy Map access and other gameplay controls.

The package metadata identifies the set as `BloodSteyn's ED Grids`.

### BlueSkunkEDgrid

File:

`BlueSkunkEDgrid.rpgp`

Creator: **BlueSkunk**

A separate Elite Dangerous Power-Grid layout recovered from the original ecosystem. The package metadata identifies it as `Elite: Dangerous`.

## Using these grids

Import the `.rpgp` file into the restored Windows Power-Grid application using the normal Power-Grid grid import workflow.

These grids were created for an older version of Elite Dangerous and may rely on key bindings chosen by their original authors. If a control does not perform the expected action, check the game's current key bindings and compare them with the actions configured in the grid.

## Preservation note

These grids are preserved as recovered community material and remain attributed to their original creators where that information is available.

Power-Grid Rescue does not claim authorship of these layouts, artwork or game-specific material. The purpose of this folder is preservation and continued compatibility with the original Power-Grid grid format.
