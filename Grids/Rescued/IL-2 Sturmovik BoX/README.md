# IL-2 Sturmovik: Battle of Stalingrad / BoX — Rescued Power-Grid Grids

Ten recovered community Power-Grid layouts for the **IL-2 Sturmovik: Battle of Stalingrad / Battle of X** flight-simulator series.

All ten packages identify **LesG** as their original author in the embedded `info.json`, with the historical site `https://lesg-derflugsektor.blogspot.de/p/startseite.html`.

## Included grids

| File | Embedded grid name / purpose |
| --- | --- |
| `IL2BoX_AllgTasten.rpgp` | General commands (*Allgemeine Befehle*) |
| `IL2BoX_ControlsService.rpgp` | Controls Service |
| `IL2BoX_Bf109E-7.rpgp` | Messerschmitt Bf 109 E-7 instruments |
| `IL2BoX_Bf109F-2.rpgp` | Messerschmitt Bf 109 F-2 instruments |
| `IL2BoX_Bf109F-4.rpgp` | Bf 109 F-4 instruments |
| `IL2BoX_Bf109F-4_UK.rpgp` | Bf 109 F-4 functions with UK keyboard layout |
| `IL2_BoX_Bf109G-2.rpgp` | Messerschmitt Bf 109 G-2 instruments |
| `IL2BoX_FockeWulf190A-3.rpgp` | Fw 190 A-3 instruments |
| `IL2BoX_MIG3.rpgp` | MiG-3 functions |
| `IL2BoX_Ju52_Motoren_vereinfacht.rpgp` | Simplified Ju 52 engine commands; one control operates all engines rather than separate controls per engine |

## Using these grids

Import the chosen `.rpgp` archive into the restored Power-Grid Windows application. These are historical control profiles, and some commands may depend on the original game's key map. In particular, the F-4 UK variant explicitly targets a UK keyboard layout; the other packages may use different bindings.

Original filenames, package contents, artwork and metadata have been retained. No current-version simulator compatibility testing is claimed. These are community-created preservation copies, not official ROCCAT or IL-2 releases.
