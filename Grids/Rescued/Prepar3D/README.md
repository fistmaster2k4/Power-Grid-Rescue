# Prepar3D

## Prepar3D v2.5 Essentials

- **Original creator:** Archie
- **Package:** `P3D.rpgp`
- **Simulator:** Lockheed Martin Prepar3D v2.5
- **Intended display:** iPad Mini, portrait orientation; Power-Grid supported iOS and Android clients
- **Original description (embedded metadata):** “Basic / Must haves for Small Aircraft like a Cessna or Baron 58 with AP / GPS”
- **Original community post:** [ROCCAT Power Grid panel for P3D (iOS/Android)](https://www.xsimulator.net/community/threads/roccat-power-grid-panel-for-p3d-ios-android.6831/) (2 May 2015)

### Controls

The panel includes landing gear, flap controls, parking brake, autopilot master, NAV/GPS toggle, map, heading hold, NAV hold, approach mode, altitude hold, and shortcuts to cockpit panels, radio, GPS and throttle.

### Setup notes from the original post

Most controls use the simulator's default keyboard shortcuts. Two require custom bindings in Prepar3D:

| Function | Keyboard binding |
| --- | --- |
| NAV/GPS toggle | `Ctrl + Shift + N` |
| Show map | `Ctrl + Shift + M` |

The original author described the grid as intended for small aircraft (such as the Cessna and Baron 58), with potential expansion to other tabs. Check key bindings against your particular simulator version and aircraft before use.
